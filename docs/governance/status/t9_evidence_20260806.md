## Defects Found

### D-T9-001 — Clients → Assessments returns 401 for cross-tenant access

**Severity:** Medium
**Finding:** The Clients → Assessments path requires a per-tenant portal API key stored at `portal:tenant:{id}:key` in Upstash. None of the existing client tenants have a portal key in Upstash, so selecting any client's Assessments returns CORE_AUTH_MISSING → 401. The core operator flow (sidebar Field Assessments as frostgate-internal) is unaffected.
**Impact:** Operator cannot view engagements scoped to a specific client tenant from the Clients list.
**Status:** Open — non-blocking for T9 DoD. Follow-up: write portal key to Upstash when provisioning client tenants.

### D-T9-002 — Wildcard scope `"*"` not mapped to platform_admin (FIXED)

**Severity:** High
**Finding:** `_permissions_from_legacy_scopes({"*"})` returned `frozenset()` because none of the explicit scope-string checks matched `"*"`. Credential-authority-issued keys with `scopes=["*"]` (including the console-bff-key) got zero permissions → 403 on every `require_permission()` gate.
**Fix:** Added early return in `_permissions_from_legacy_scopes`: `if "*" in scopes: return roles_to_permissions(["platform_admin"])`.
**Commits:** main `6299daac`, exec `1d6133ad`. Deployed same session.

### D-T9-003 — Dark mode date input calendar invisible (FIXED)

**Severity:** Low
**Finding:** Native `<input type="date">` calendar picker inherited the dark theme background, making the calendar UI invisible in dark mode.
**Fix:** Added `className="[color-scheme:light] dark:[color-scheme:dark]"` to the scheduled-date input in `apps/console/app/field-assessment/page.tsx`.
**Commits:** main `7a2ed2f9`, exec `760946c7`. Deployed same session.

### D-T9-004 — Verification bundle generation fails

**Severity:** Low
**Finding:** The "Generate Bundle" button in the Reports tab returns "Failed to generate bundle. Please try again." The failure mode and root cause were not investigated during T9.
**Impact:** Verification bundles (regulatory-grade SHA-256 snapshots) cannot be generated from the console UI. This path is not required by T9 DoD.
**Status:** Open — investigate post-T9.
