Real data rendering validation is deferred to the **first live client engagement** where:
1. A client tenant exists with a provisioned portal key
2. An engagement has been completed with real findings

This deferral is non-blocking for v1.0 launch. The portal mechanics (auth, sessions, revocation) are production-proven. Data rendering depends on client tenant provisioning which is covered by the IA-1 provisioning flow (COMPLETE 2026-08-03).
